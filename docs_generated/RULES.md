# Quy tắc bảo toàn
1. Không sửa, xóa, đổi tên, di chuyển file/thư mục gốc của repo.
2. Chỉ được tạo file mới trong docs_generated/. Không ghi đè file có sẵn.
3. Không tự suy đoán. Thiếu nguồn trong repo thì ghi "Chưa rõ - cần xác nhận".
4. Mọi đường dẫn được dẫn trong tài liệu phải tồn tại trong repo.
